เกมนี้ฝึกอะไร

  • 🩺
    ข้อมูลซ่อนตามบทบาท (hidden information) — Patient ถือข้อมูลประวัติ, Facilitator ถือผล PE/Investigation ทีมต้อง "ถาม" และ "ขอตรวจ" ให้ตรงจุดเพื่อปลดล็อกข้อมูล
  • 🧠
    System 1 vs System 2 — Bias monitor นำ diagnostic time-out ไล่ checklist และดักจับ cognitive bias ระหว่างทาง
  • 📋
    Problem list / Problem representation — Scribe เขียนร่วมกับทีม แล้วเทียบกับ expected PL/PR พร้อมให้คะแนนโดย facilitator
  • 🌐
    เอกสารทางคลินิกเป็นภาษาอังกฤษล้วน — ผล PE, Problem list และ Problem representation บังคับเป็น medical English เพื่อฝึกเขียนบันทึกแบบมาตรฐาน
  • 🎮
    ธีมย้อนยุค 8-bit — สไปรต์พิกเซล เสียงเอฟเฟกต์และเพลงประกอบสังเคราะห์เองทั้งหมด ไม่มีไฟล์เสียงภายนอก

อยากลองเล่น?

เกมนี้เล่นได้ฟรีบนเว็บ สร้างห้องแล้วส่งรหัส 4 ตัวอักษรให้เพื่อนอีก 3–5 คนเข้าร่วม (ต้องมีอย่างน้อย 4 คน) เปิดครั้งแรกอาจรอเซิร์ฟเวอร์ตื่นราว 30 วินาที
